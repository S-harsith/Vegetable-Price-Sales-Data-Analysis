# Vegetable Price & Sales Data Analysis

Analysis of 2.76 million rows of vegetable price and sales data using
Databricks, PySpark and SQL.

## Project summary
- Data: 2.76 million rows, 19 vegetables, 1 Jan 2024 to 23 sep 2026
- Removed 1,951 duplicate rows to keep the data accurate
- Cleaned and transformed the data using PySpark and SQL
- Analyzed monthly and vegetable-wise price trends
- Built charts to show price changes over time

## Key finding (tomato)
- Highest average price: 64.19 on 20 June 2024
- Lowest average price: 11.80 on 27 March 2025
- Prices were very unstable, with sharp spikes and drops
  (about 5 times difference between the highest and lowest)

## Notebook
vegetable_price_analysis.ipynb - cleans the raw data, removes duplicates,
and plots price trends (for example, tomato).

## Tools
Databricks, PySpark, SQL, Python
